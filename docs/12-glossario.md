# 12 — Glossário de empreendedorismo

Definições simplificadas para acompanhar a aprendizagem e preparar o pitch.

| Conceito | Significado aplicado à Modernize |
| --- | --- |
| **B2B** | Vender serviços ou produtos de uma empresa para outra empresa. |
| **Persona** | Perfil de quem usa ou decide contratar. Usuário e comprador podem ser pessoas diferentes. |
| **Proposta de valor** | Benefício concreto e relevante que a empresa promete entregar. |
| **Hipótese de valor** | Suposição sobre o benefício, a ser verificada com evidências. |
| **MVP** | Versão mínima do serviço/produto capaz de testar sua proposta central. |
| **PMF** | Product-Market Fit: sinais de que uma oferta satisfaz uma demanda real. |
| **TAM** | Mercado potencial total. |
| **SAM** | Parte do TAM efetivamente atendível pela oferta e operação. |
| **SOM** | Parte realisticamente conquistável do mercado atendível. |
| **GTM** | Go-to-Market: canais e estratégia para vender/lançar a oferta. |
| **Canvas** | Quadro de hipóteses sobre modelo de negócio. |
| **SaaS** | Software cobrado como serviço recorrente, em geral por assinatura. |
| **Freemium** | Oferta gratuita básica com recursos/serviços pagos adicionais. |
| **ARPU** | Receita média por usuário ou cliente num período. |
| **CAC** | Custo médio para adquirir um cliente; inclui esforço comercial. |
| **LTV** | Contribuição esperada gerada pelo cliente durante a relação comercial. |
| **Churn** | Taxa de cancelamento ou perda da base em período definido. |
| **LTV:CAC** | Relação entre contribuição ao longo da relação e custo de aquisição. |
| **Payback** | Prazo para recuperar o custo de aquisição a partir da contribuição. |
| **Margem de contribuição** | Receita menos custos variáveis diretamente associados à entrega. |
| **Break-even** | Ponto em que a contribuição cobre os custos considerados. |
| **Burn líquido** | Quanto o caixa diminui num período (saídas menos entradas). |
| **Runway** | Quantos meses o caixa pode sustentar o consumo de recursos. |
| **OPEX** | Gastos operacionais recorrentes, como salários e licenças. |
| **CAPEX** | Investimento em ativos de uso duradouro, sujeito a critérios contábeis. |
| **SWOT/FOFA** | Forças, fraquezas, oportunidades e ameaças. |
| **Pivotar** | Mudar hipótese central de negócio após aprendizado com evidências. |
| **Computer use** | IA interagindo com interfaces de software, sujeita a acesso, segurança e supervisão. |

**Ressalva:** várias fórmulas ensinadas na disciplina partem de SaaS mensal. Para serviços por projeto, a Modernize precisará adaptar a unidade econômica com transparência.
