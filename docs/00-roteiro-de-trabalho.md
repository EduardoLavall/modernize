# Roteiro de trabalho — Modernize

**Versão:** 0.1 — 15/10/2026

## Método combinado

Processo: **GRILL ME (perguntas críticas, uma por vez) → definição → documentação → repositório → implementação one-shot → microajustes → ensaio e apresentação**.

A equipe quer aprender os conceitos técnicos de empreendedorismo conforme forem aplicados. A documentação deve explicar cada conceito e dar exemplos do negócio.

## Regra de qualidade

Cada informação deve aparecer como uma destas categorias:
- **Decisão:** tomada explicitamente pela equipe.
- **Hipótese:** plausível, mas ainda não comprovada.
- **Evidência:** dado verificável com fonte, método e data.
- **Pendente:** depende de pesquisa ou escolha futura.

Nenhum indicador, cliente entrevistado, resultado de PMF, receita ou tamanho de mercado é considerado validado nesta versão.
